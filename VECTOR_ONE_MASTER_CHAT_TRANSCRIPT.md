### 🛠️ Root Cause & Technical Fix:

1. **Tailwind CSS Media Query Collision:**  
   The tab content elements previously had `hidden` (`display: none`) and `lg:grid` (`display: grid`) declared on the exact same HTML tag. On desktop screens (greater than 1024px wide), Tailwind's `@media (min-width: 1024px)` rule took CSS precedence over `.hidden`, causing tab switching to be overridden by desktop grid display rules.

2. **Isolated Display Structure:**  
   We wrapped each pillar section in an isolated container div (`<div id="content-[pillar]" class="pillar-content hidden">`), moving the responsive grid layout inside.

3. **Explicit Click Pointer UX:**  
   Added `cursor-pointer` to all 5 tab buttons so hover states explicitly show pointer cursors.
