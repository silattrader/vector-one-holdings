# Enterprise AI Data Sovereignty & Zero-Retention SLA

**Provider:** Vector One Holdings (Vector Compute / Vector Intelligence)  
**Applicability:** EvoMax Token Engine & Agent-as-a-Service (AaaS) Deployments  

---

## 1. Data Sovereignty Guarantee

Vector One Holdings guarantees that all enterprise data, API payloads, telemetry, and workflow documents processed by our platforms remain strictly within **sovereign Malaysian cloud infrastructure** (or the mutually agreed jurisdiction).

*   **Cloud Partners:** Vector One utilizes Telekom Malaysia (TM ONE) and AWS Sovereign (Malaysia) Availability Zones.
*   **Compliance:** Full compliance with the Personal Data Protection Act 2010 (PDPA) of Malaysia, Bank Negara Malaysia (BNM) RMiT guidelines, and MCMC frameworks.
*   **Cross-Border Data Flows:** Data will not be routed outside the sovereign zone without explicit opt-in for specific third-party API processing (if selected by the client).

## 2. Zero Data Retention SLA (EvoMax Engine)

Vector One’s EvoMax Token Compression Engine is designed with a fundamental privacy-first architecture:

*   **RAM-Only Processing:** All semantic deduplication and prompt compression occurs in volatile memory (RAM).
*   **Zero Storage:** Vector One does not log, store, or persist user prompts, sensitive enterprise context, or generated LLM responses to any disk storage.
*   **Caching Layer:** Any enterprise-approved semantic caching utilizes aggressive Time-To-Live (TTL) policies (e.g., 24-72 hours) and can be disabled entirely for highly classified workflows.

## 3. Strict Non-Training Guarantee

Under no circumstances will Client data processed through Vector Compute or Vector Intelligence be used to fine-tune, train, or improve foundational LLMs, nor will it be shared with any third-party model providers for their training purposes.

## 4. Audit & Transparency

Clients maintain the right to:
*   Request annual penetration testing summaries and SOC2 Type II compliance reports.
*   Perform on-site or remote audits of the deployment architecture (subject to 30 days' notice).
*   Receive full network routing tables confirming data path isolation.
