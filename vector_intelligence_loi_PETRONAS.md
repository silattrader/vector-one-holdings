### 1. Purpose
This Letter of Intent ("LOI") outlines the mutual understanding between Provider and Client to enter into a 45-day technical and operational pilot program ("Pilot") to evaluate the **Vector Intelligence AI Agent-as-a-Service (AaaS) Platform**, powered by the **EvoMax Token Engine**. The Pilot aims to validate agentic automation capabilities, cost-efficiency, and LLM latency optimization within PETRONAS's existing enterprise workflows and data ecosystems.

### 2. Scope of the Pilot Program
During the Pilot phase, Provider will deploy a dedicated, secure instance of the Vector Intelligence AaaS platform. This will feature a pre-configured AI Agent targeting a specific, mutually agreed-upon workflow (e.g., automated supply chain reporting, HSE compliance triage, or internal HR/IT support inquiries).
The Pilot is designed to benchmark and demonstrate the following outcomes:
*   **Workflow Automation:** Automation of at least 30-40% of the designated manual workflow process without sacrificing accuracy.
*   **Cost & Latency Optimization (EvoMax):** Target token volume and cost reduction of 30-40% on underlying LLM API calls, alongside measurable response latency reductions for agentic queries.
*   **System Integration:** Successful, secure API integration with PETRONAS's legacy ERP, CRM, or data lake systems (e.g., SAP, Microsoft Azure).
*   **Language & Context Accuracy:** High-fidelity performance in Bahasa Malaysia and English, with strict adherence to PETRONAS's corporate compliance guardrails.

### 3. Pilot Deployment & Responsibilities
*   **Provider Responsibilities:** Vector One will handle the initial agent configuration, prompt engineering, EvoMax middleware routing, and deployment into a staging environment. Provider will offer a comprehensive onboarding session for PETRONAS Digital/IT personnel and produce an "Automation ROI & Token Savings Report" at the conclusion of the Pilot.
*   **Client Responsibilities:** PETRONAS agrees to provide necessary API access/credentials to a staging environment (or sanitized production data) and allocate subject matter experts (SMEs) from the PETRONAS Digital team to evaluate the AI Agent's performance and token routing efficiency for approximately 2-4 hours per week during the Pilot.

### 4. Commercial Terms Upon Success
Should the Pilot successfully demonstrate the target metrics outlined in Section 2, PETRONAS intends to enter into a commercial agreement for a full enterprise license of the Vector Intelligence AaaS Platform and EvoMax API. The anticipated commercial agreement structure will include an annual platform license fee and volumetric token pricing, aiming to guarantee a 12-month ROI through operational cost reductions and optimized compute spend.

### 5. Confidentiality, Security & Data Sovereignty
*   **Data Sovereignty & Zero Data Retention:** Provider guarantees that all enterprise data processed by the AaaS platform and EvoMax middleware remains within Malaysia (utilizing sovereign cloud deployments) in compliance with the Personal Data Protection Act (PDPA) and PETRONAS data governance policies. Data passed through EvoMax is processed in volatile RAM only and is never used for model training.
*   **Confidentiality:** A formal Mutual Non-Disclosure Agreement (MNDA) is executed concurrently with this LOI.

### 6. Non-Binding Nature
This LOI represents a statement of mutual intent and is non-binding, with the exception of Section 5 (Confidentiality), which is legally binding upon signature.
