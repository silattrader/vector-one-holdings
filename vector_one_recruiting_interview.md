## Part I: Key Executive Job Descriptions

### 1. Lead AI Compute Architect (Vector Compute)
- **Role Summary:** Lead the engineering and optimization of the **EvoMax Token Engine**. You will architect low-latency API proxy gateways, implement semantic context compression algorithms, and build enterprise SLAs for MiniMax & frontier LLM token distribution.
- **Key Responsibilities:**
  - Architect dynamic C/C++ or Rust/Go API routing middleware handling 100M+ daily tokens.
  - Implement token compression algorithms (pruning, semantic deduplication) reducing latency by >100ms.
  - Oversee SOC2 Type II compliance controls for zero-data-retention RAM processing.
- **Qualifications:** 7+ years experience in distributed systems, C++/Rust, LLM inference optimization, and high-throughput API gateways.

### 2. VP of Aerospace & Defense Systems (Vector Aero)
- **Role Summary:** Direct technical and operational execution for **Vector Aero**. Oversee commercial drone fleet operations, radar/RF sensor ingestion, counter-drone (C-UAS) electronic jamming, and defense procurement.
- **Key Responsibilities:**
  - Lead deployment of C-UAS perimeter security systems for airport, military, and infrastructure clients.
  - Interface with aviation regulatory bodies (CAAM, FAA) to ensure frequency spectrum compliance.
  - Manage hardware-software integration between physical sensors and automated C2 software.
- **Qualifications:** 10+ years in aerospace engineering, C-UAS/RF systems, or military avionics operations.
